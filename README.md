# Agrotech Agriculture

Official website for Agrotech Agriculture Industry in Jhang, Punjab, Pakistan.

## Website sections

- Home
- Agricultural products and individual product pages
- Laser transmitters, receivers and control systems
- About Agrotech
- Contact details, WhatsApp and interactive location map

## Local preview

Run:

```powershell
node preview-server.mjs
```

Open `http://127.0.0.1:4173/`.

## Deployment

The production-ready static website is stored in `dist/`. `vercel.json` configures Vercel to publish that directory.
